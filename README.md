## 三座大殿

### 🎲 神谕阁 · 每日一卦
把「今天吃什么」这个世纪难题外包给封建迷信。每日抽取一支麦运签：签诗、宜忌、今日麦运套餐、幸运单品、开运方位、麦运指数，一应俱全。
- 每天只能抽一签（天机不可泄露），但提供「强行逆天改命」按钮
- **周四自动进入疯狂状态**，所有卦象强制替换为【疯狂星期四·天命】，附发疯文学
- 接入 MCP 后，推荐套餐由当日真实活动日历（`campaign-calendar`）与你的可用优惠券（`query-my-coupons`）驱动

### ⚖️ 审判庭 · 订单审判
仿麦当劳点餐系统的完整点餐界面：横向品类 tab（超值套餐/主食汉堡/小食/甜品/饮品/早餐）、套餐大卡（主食+中薯+中饮，划线原价）、底部购物车、结算浮层。**31 个 SKU 的品名与配图全部对齐官网标准产品线**（每个品名都能在官网菜单页找到同名产品），价格对齐大陆门店 2026 年公开价格体系。

**今日券讯模块**——调研自麦当劳中国官网活动新闻的真实优惠：10/15-10/21 早餐两件套 ¥9.9、周六麦金喜积分霸王餐、9.9 大薯条、麦乐鸡买一送一……每天按日期轮换「今日可领券」，领了才抵扣，不领就开庭——法官会查证你一张券没领，宣判血亏金额，砸下公章判决书，附「赎罪清单」教你同款订单怎么下单最省。
- 羞辱式省钱：被骂完还想转发
- 判决等级五档：无罪释放 / 精打细算 / 平平无奇 / 败家玩意 / 麦门叛徒
- 不服可上诉，二审法官更毒舌（终审判决，不得再上诉——其实是法官懒得再审了）
- 调研来源存档：`docs/coupon-research-2026-10-16.md`（含每日更新链路）
- 接入 MCP 后，价格核算走 `calculate-price`，优惠券查证走 `query-store-coupons` / `auto-bind-coupons`，菜单走 `query-meals`，每日自动更新真实券

### 📜 轮回司 · 麦门人生 Galgame
如果每顿都吃麦当劳，你的人生会重开成什么样？这是一个 **108 个剧情节点的分支人生 Galgame**：开心乐园餐怎么选、晚自习后去哪、百团大战加哪个社、暑假五条路走哪条……每个场景 3-5 个选项，每次选择都在改写四维属性（体重/钱包/信仰/健康）、解锁剧情旗标、走向完全不同的线路。

## 安装与运行

**零依赖，开箱即用：**

方式一：直接双击 `index.html` 用浏览器打开（演示数据模式）。

方式二：本地起服务（推荐，支持真实数据加载）：

```bash
cd mcmultiverse
python -m http.server 8080
# 打开 http://localhost:8080
```

方式三：GitHub Pages。仓库 Settings → Pages → 选 main 分支根目录，即可获得公开可玩的链接。

## 接入真实麦门数据（可选）

页面默认使用内置演示数据。想让三座大殿跑在真实数据上：

1. 到 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp) 申请 MCP Token
2. 按 `mcp-config-example.json` 在任意 MCP Client（推荐 WorkBuddy）中配置连接器
3. 让 AI 调用 `query-meals`、`query-store-coupons` 等 Tool，将返回结果导出为 `data/mcd-real-data.json`（格式参考 `data/mcd-real-data.example.json`）
4. 页面启动时自动检测并切换到真实数据，签文卡会亮起「MCP 真实数据」徽章

详细的 Tool 调用流程见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)。

## 餐品图片素材来源

审判庭的每一张餐品图都是**真实官方产品图**，不使用图标或 AI 生成图：

- 来源：麦当劳中国官网 <https://www.mcdonalds.com.cn> 各分类菜单页（汉堡 / 小食 / 甜品 / 饮品 / 早餐 / 开心乐园餐 / 麦咖啡）
- 规格：640×640 官网原图（存于 `assets/menu_raw/`）→ 裁掉透明留白 → 512×512 透明 PNG（存于 `assets/menu/`）
- 覆盖：21 张图对应菜单 31 个 SKU，套餐与同系列规格复用主食图，与真实点餐系统做法一致
- 零替代：所有 SKU 均为官网同名产品，不含任何"用别的产品图顶替"的近似配图（`tools/align_menu_to_official.py` 记录了对齐过程）
- 更新：`fetch_menu_images.py` → `download_menu_images.py` → `trim_menu_images.py` → `inject_menu_images.py` 四步可复跑，官网菜单变动后重新抓取即可
- 加载失败时自动降级为 emoji 图标，不会出现破图
