## 公网边界（默认本机行为不变，109 项测试含 5 项新增）

| 边界 | 行为 |
| --- | --- |
| Host | 本机模式仅 127.0.0.1/localhost；公网模式可配 `TRIAD_ALLOWED_HOSTS`，未配置时放行（平台反代改写 Host 且不透传 forwarded-host，无法白名单） |
| Origin | 配置 `TRIAD_ALLOWED_ORIGINS` 后严格校验；未配置时交给 `Sec-Fetch-Site` + 限流把关 |
| 跨站 | 始终拒绝 `Sec-Fetch-Site: cross-site` |
| 限流 | 每 IP 180 次/分钟（API），超出 429 |
| 会话 | 全局 64 局上限 + 每 IP 8 局上限 |

## 部署过程中的两次修复（关键教训）

1. 首次上线后 `health` 直连 200，但带浏览器 `Origin` 的请求 403：部署平台反代**改写 Host 且不透传 `x-forwarded-host`**，服务端按 Host 还原自域名必然算错。
2. 第一次修复（信任 `x-forwarded-host` 构造白名单）线上仍 403，确认该平台两个头都拿不到；最终改为「未配置白名单时不做 Origin 等值匹配」，同源 200、跨站 403、限流兜底。
