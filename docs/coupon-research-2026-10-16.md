## 三、每日更新链路（接入 MCP 后）

```
每日 09:00  WorkBuddy 定时任务
  → MCP campaign-calendar      当月活动日历
  → MCP available-coupons      麦麦省可领券列表
  → MCP query-my-coupons       我的优惠券
  → MCP query-meals            门店实时菜单
  ↓ 汇总导出
data/mcd-real-data.json        { menu: [...], coupons: [...] }
  ↓ 页面 fetch 自动替换
审判庭「今日券讯」+ 菜单全部切换真实数据，亮 MCP 徽章
```
